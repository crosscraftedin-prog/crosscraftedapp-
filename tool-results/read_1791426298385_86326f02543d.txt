     4→
     5→Built a full CMS for managing Bible Comic chapters, panels, translations,

     8→### Schema changes
     9→- `ComicChapter`: added `status` (default "draft"), `description`, `adminNotes`,
    10→  and `@@index([status])`. Existing rows back-filled automatically by Prisma
    11→  with status="draft".

    15→### Admin API routes (all under `/api/admin/comics`)
    16→- `GET /api/admin/comics` — list chapters with panel/translation/quiz counts.
    17→  Supports `?status=`, `?book=`, `?q=` filters.
    18→- `POST /api/admin/comics` — create chapter. Validates bookId against
    19→  `BIBLE_BOOKS`, auto-generates `comicId` as `{bookId}-{chapter}`.
    20→- `GET /api/admin/comics/[id]` — single chapter with all panels + translations.
    21→- `PATCH /api/admin/comics/[id]` — update chapter. Supports moving the chapter
    22→  to a new (bookId, chapter) combo — cascades the denormalized book/chapter
    23→  on every existing panel.
    24→- `DELETE /api/admin/comics/[id]` — hard delete (cascade cleans panels + trans).
    25→- `POST /api/admin/comics/[id]/panels` — create panel. Auto-generates panelId
    26→  using `{BOOKABBR}{CH}-P{NN}`. Auto-seeds an empty English translation row.
    27→- `PATCH /api/admin/comics/[id]/panels/[panelId]` — update panel fields.
    28→- `DELETE /api/admin/comics/[id]/panels/[panelId]` — delete panel.
    29→- `POST /api/admin/comics/[id]/publish` — runs validation, sets status=
    30→  "published" + isActive=true. Returns list of errors if validation fails.
    31→- `POST /api/admin/comics/[id]/unpublish` — sets status="draft", isActive=false.
    32→- `POST /api/admin/comics/[id]/duplicate` — clones chapter + panels + trans
    33→  + quiz links into a new draft. Generates fresh panelIds.
    34→- `GET /api/admin/comics/[id]/quiz?q=` — returns linked questions + search
    35→  results from `TriviaQuestion` (uses `questionId` join).
    36→- `POST /api/admin/comics/[id]/quiz` — link a question.
    37→- `DELETE /api/admin/comics/[id]/quiz/[questionId]` — unlink.
    38→- `POST /api/admin/comics/[id]/translations` — upsert panel or chapter
    39→  translation. Validates lang against the 13 supported languages.
    40→- `GET /api/admin/comics/stats` — aggregate dashboard stats (totals,
    41→  missing-artwork counts, missing-EN-translation counts, missing-quiz counts)
    42→  in a single query.
    43→

   174→- Root cause identified: Supabase Storage path is deterministic (bible-comics/{bookId}/{chapter}/{panelId}.webp). Re-uploading to the same panel UPSERTS at the SAME URL. This caused two failure modes:
   175→  1) React: setArtwork(sameUrlString) is a no-op (state value unchanged) → <img> never re-renders → preview shows OLD image.
   176→  2) Browser cache: even if <img> did re-render, browser serves cached image at that URL.
   177→- Fix: Append cache-busting ?v={Date.now()} query param to URLs returned from /api/admin/comics/upload.
   178→  - Upload API response: url + artworkUrl now include ?v=<timestamp>
   179→  - DB stores artworkUrl WITH ?v=<timestamp> (so reopening editor shows the version that was last uploaded)
   180→  - Each new upload bumps ?v= → URL string differs from previous state → React re-renders <img>
   181→  - Browser sees different URL → fetches freshly-uploaded file
   182→  - Query param is harmless — Supabase Storage ignores it
   183→- Verified ComicView.tsx uses panel.artworkUrl directly in <img src> — works fine with ?v= query param.
   184→- Verified PATCH endpoint /api/admin/comics/[id]/panels/[panelId]/route.ts stores artworkUrl as-is (no change needed).
